Overview

BaseAI combines decentralized GPU compute (DePIN), AI inference, zero-knowledge machine learning (zkML), and autonomous agents into a unified DeFi protocol built on Base (Optimism Layer 2).

The ultimate goal is to create a self-evolving, AI-native financial ecosystem with > $55 million TVL by the end of 2026, where AI agents manage capital, verify computations, optimize yields, and govern the protocol in a fully decentralized manner.

What is zkML? Detailed Explanation

zkML (Zero-Knowledge Machine Learning) is a groundbreaking technology that combines machine learning with zero-knowledge proofs (ZKP). It allows you to mathematically prove that an AI model correctly processed input data and produced a specific output — without revealing the input data, the model weights, or any intermediate computations.

In simple terms: zkML turns AI into a verifiable "black box". You can trust the result on-chain without trusting the off-chain computation. This is critical for DeFi, where AI is used for predictive yields, risk scoring, automated trading, and agent decisions — but trustlessness is non-negotiable.

Why zkML Matters in 2026

  • AI in DeFi is exploding: agents trade, score risks, generate assets — but how do you prove the model wasn't manipulated?
  • Privacy: Your portfolio, transactions, or strategy remain completely hidden.
  • Scalability: Heavy ML runs off-chain (cheap/fast), while tiny proofs (~1KB) are verified on-chain for pennies (Base L2 gas ~$0.01).
  • Real progress: EZKL proves nanoGPT in minutes on GPU; Modulus Labs verifies GPT-2; Cysic ASICs speed up 50x; projects like Worldcoin, Lagrange, Gaianet already use zkML in production.

How zkML Works Step-by-Step

  1. Classical ML (without zk): Model M + Input I → Output O. Problem: No one can verify if M was applied correctly to I.
  2. zkML adds ZKP:
    • Prover (off-chain): Runs inference on M(I) = O, generates a cryptographic proof that "I correctly applied M to I and got O".
    • ML operations (matrix multiplications, ReLU, softmax) are converted into arithmetic circuits/polynomials over finite fields.
    • Tools: EZKL (GPU-accelerated, Python-friendly), zkLLM (for LLMs), Circom/Noir (circuit DSLs).
  3. Verifier (on-chain): Receives proof + public O → checks validity in milliseconds. If valid → accept O (e.g., approve loan, execute trade).

Mathematical Core (Simplified)

The proof is a ZK-SNARK/STARK statement:

M(I) = O    (proven without revealing I or M internals)
  • SNARKs (Groth16/Plonk): Compact (~200 bytes), fast verification, but require trusted setup.
  • STARKs: No setup, quantum-resistant, larger proofs (~kB).
  • Non-linear ops (ReLU, sigmoid) approximated via polynomials or lookup tables.
  • Constraint count: 10⁹–10¹² for large models like Llama-70B → minutes on GPU, seconds on ASIC.

Glossary of Key Terms

This glossary covers the core concepts used across BaseAI documentation. Terms are listed in alphabetical order.

Agent SDK
Software development kit for building and deploying autonomous AI agents on BaseAI. Includes tools for planning, tool-use, on-chain execution, and zk-verification (Phase 4 target: 50,000+ users).
Autonomous Agent
An AI entity capable of perceiving its environment, planning actions, using tools, executing on-chain transactions, and adapting goals without continuous human intervention. In Phase 4, agents manage treasury, optimize yields, and propose governance changes.
Bidding Engine
A real-time auction system in the Inference Marketplace that matches user inference requests with the optimal available compute node based on price, latency, and reliability.
DAO Scaling
Expansion of decentralized governance participation. Phase 3 target: ≥ 10,000 active voters; Phase 4 → full on-chain control with AI-assisted proposals.
DePIN
Decentralized Physical Infrastructure Network. A token-incentivized network of distributed physical hardware (in this case, GPUs) that provides compute resources to the protocol.
Genesis Badge
An early-access non-transferable NFT distributed during Phase 1. Holders receive boosted staking rewards, priority access to future features, and enhanced governance voting power.
Inference
The process of running a trained AI model on input data to generate outputs (predictions, text, images, etc.). Opposite of training. BaseAI's marketplace focuses on decentralized inference.
Model Registry
An on-chain catalog of available AI models, including metadata (version, creator, performance metrics, supported tasks), enabling discoverability and usage in the Inference Marketplace.
Node CLI
Command-line interface tool for node operators to easily join the DePIN network, register hardware, and start earning from inference tasks.
Optimism Bridge
Cross-chain bridge connecting Base (L2) to Ethereum mainnet and other Optimism-based chains, enabling asset and data transfer in Phase 3.
Proof Verification
The on-chain process of checking a zero-knowledge proof. In BaseAI, verification is gas-optimized to cost pennies on Base L2, enabling scalable zkML usage.
Revenue Share
Distribution of protocol fees (from inference, zkML jobs, agent execution) to node operators, model creators, stakers, and treasury (with portions burned for deflation).
TVL (Total Value Locked)
The total amount of assets committed to BaseAI contracts (staking pools, liquidity, agent-managed funds). A primary metric of protocol adoption and economic activity.
zk-SNARK
Zero-Knowledge Succinct Non-Interactive Argument of Knowledge — a widely used zero-knowledge proof system (Groth16, Plonk) that enables compact, fast-verifiable proofs. Used in zkML for on-chain verification.
zkML (Zero-Knowledge Machine Learning)
A cryptographic technique that proves correct execution of machine learning inference without revealing inputs, model weights, or intermediate computations. Enables private, verifiable AI in DeFi and autonomous agents.
zkVM
Zero-Knowledge Virtual Machine. A general-purpose zk-proof system (e.g., RISC Zero, zkWASM) that can execute arbitrary code (including ML models) and prove correctness. zkML often builds on zkVMs for flexibility.
